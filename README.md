# 示波器波形抓取工具

Scope Capture 由 James Gao 编写，通过局域网连接示波器并保存原生截图、波形 CSV、AI JSON 和重绘图。

## 下载与启动

1. 到 [Releases](https://github.com/James-2937/ScopeCapture-Downloads/releases) 下载 Windows x64 便携 ZIP。
2. 将 ZIP 完整解压到可写目录，双击 **run.bat**。
3. 按编号选择一台预设的示波器，也可输入仪器面板上的 IPv4 地址。随后选择输出。采集一轮后，回车沿用当前标签续抓，按 **L** 改标签后续抓，按 **Q** 退出。采集文件默认保存在解压目录的 **waveform** 文件夹。

支持 Keysight DSOS404A、Keysight DSOX1204A、Tektronix TBS2204B 和 Rohde & Schwarz MXO54。
每个版本附有中文用户指南、发布说明、应用使用许可和第三方许可。
